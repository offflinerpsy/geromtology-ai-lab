# Cloudflare production release — 11 October 2026

## Release

ProAge Atlas now runs independently on Cloudflare Workers at https://proage-atlas.offflinerpsy.workers.dev. The authoritative source is `offflinerpsy/geromtology-ai-lab`, branch `cloudflare/production`.

Initial production commit: `06d7b66dc1246f0cd963ebea4ee43a42665ac197`.

Cloudflare Workers Builds completed a clean dependency install, TypeScript validation, all 20 numerical/content/security tests, the server and asset build, and production deployment for that commit. The production build configuration watches `cloudflare/production`; this release note is also a follow-up commit for checking the repository-triggered build.

## Migration

- Preserved audited Sites version 12, the approved homepage, WebGL hero, cellular parallax, laboratory motion, research routes and calculators.
- Removed Sites-only build/runtime dependencies from the independent application.
- Moved enquiries and rate limits into the owner's Cloudflare D1 database.
- Replaced ChatGPT identity with Cloudflare Access email verification. Signed JWT verification checks issuer, audience, expiry and signature. The private inbox has a separate owner-only policy.
- Kept Azure credentials in Worker secrets. No credential appears in the repository or browser configuration.
- Added English product, architecture, contribution, deployment, ownership and issue/PR documentation.

## Verification

Eighteen public pages/resources returned HTTP 200, including the laboratory routes, calculators, sitemap, robots, share image and evidence status endpoint. Page canonicals use the new Cloudflare origin.

A clearly labelled synthetic enquiry was accepted with HTTP 201 and confirmed persisted in D1 by its receipt ID. Invalid and cross-origin contact requests were rejected. Anonymous evidence status reports the server-side Azure provider is configured; this does not establish a successful signed-in AI response.

These checks were HTTP/API and build checks. A supported managed browser was unavailable, so real browser navigation, responsive presentation, sign-in, an authenticated AI answer and animation frame rate remain unverified. Automatic enquiry email forwarding is not configured; accepted enquiries are stored in the protected inbox.

## Recovery

The earlier GitHub implementation is preserved at `backup/before-cloudflare-migration-20261011` (`000dce2050389f88f21967cf60d3629af272ebae`). The original audited Sites version 12 remains a separate recovery copy at source commit `341b87f0ff3081537ae5a59989d35c8937d6cd16`.
